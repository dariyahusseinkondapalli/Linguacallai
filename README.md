# LinguaCall AI Android beta 0.2.0

Download LinguaCall-AI-0.2.0-arm64.apk from this branch using GitHub's Download raw file button.

ARM64 Android 7+; Android 13+ recommended. This standalone beta includes the JS bundle
and uses a development signing key. Provider/backend configuration is required;
no service, account, key or TURN relay is bundled. See BETA_GUIDE.md.

Build, release lint, APK signature, 15 automated tests and browser UI smoke checks
passed. Physical-phone, Bluetooth, speech-quality and two-device media tests have
not been performed. This branch holds download artifacts only. Application source
is on feat/mobile-foundation and reviewed in pull request #1.

Verify the APK against SHA256SUMS.txt. APK_BUILD.json records the source commit.
